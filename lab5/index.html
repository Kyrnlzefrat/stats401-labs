Part C: Design Description and Network Questions

C1. Node-Link Design

The node-link view uses color for district, size of each node for daily passenger volume, and shape represents station type. In this case, Larger nodes indicate higher passenger volume, and different shapes distinguish Local, Transfer, and Terminal stations. Link width represents travel time between two stations and link color represents route type. Hover highlighting emphasizes a station and its neighbors, while tooltips show station attributes and dragging helps explore the network structure.

C2. Matrix Design

The matrix uses rows and columns for stations and filled cells for direct connections. Cell color represents route type and color opacity represents travel time. Station labels are colored by district (similar with C1), with stations ordered by district and then station type. This ordering makes connection patterns easier to identify while preserving important route information.

C3. Network Questions and Findings

  1. Central stations — Can be answered well, node-link: stations with three connections, including Stations 16, 18, 21, 23, 25, 29, 31, 33, 34, and 38, appear most central. When looking at the node-link view, these stations are prominently displayed due to their high connectivity.
  2. Strongly connected districts — Can be answered well, matrix: Accoring to the matrix, East–South has the most direct connections (11), followed by Central–North and East–West (9 each).
  3. Transfer/terminal topology — Can be answered well, node-link: distinct shapes show these stations clearly; several, including Stations 29, 31, 34, and 38, are highly connected. Normally they have several edges connecting to other stations.
  4. High passenger volume — Can be answered well, node-link: node size shows that Station 50 has the highest volume, followed by Stations 49 and 48. It can be seen by the large size of the node.
  5. Longest connections — Can be answered well, both: the thickest/darkest connection is Station 7–31 (16 min, Express), followed by Station 18–34 (15 min, Express). Both can be found by checking the link widths in the figure. It can also be shown by the opacity of the cells in the matrix.
  6. Route-type concentration — Partially, both: route types are broadly distributed, with some variation between district pairs but no strong overall concentration. There is no specific feature can be found to identify a strong concentration in specific region in the figures, neither a specific colored cell can be found in the matrix.
