This is Lab 4 for STATS 401. This project demonstrates a complete workflow for transforming web data into a form suitable for visualization. Bitcoin-related tweets were collected from a public dataset, cleaned and standardized, processed using natural language techniques, and analyzed with a RoBERTa sentiment model. The resulting tidy data were then visualized using D3.js.

1. Web Data Acquisition

The dataset contains Bitcoin-related tweets together with additional tweet and user attributes, including date, user location, follower count, hashtags, source, and retweet information. A sample of tweets distributed across the full time range of the dataset was extracted rather than using only consecutive records.

2. Data Cleaning and Preparation

The raw web data were inspected for missing values, duplicate tweets, inconsistent data types, malformed records, and invalid values. Relevant date fields were converted into standardized date formats, numerical attributes were converted to numeric types, and tweet text was cleaned before sentiment analysis. Missing values in optional metadata fields were retained where they represented unavailable information rather than valid observations.

3. Text Processing and Sentiment Analysis

Tweet text was normalized by removing or replacing elements such as URLs, mentions, and other unnecessary tokens while preserving the information needed for sentiment analysis. The cleaned text was then analyzed using a Twitter-specific RoBERTa sentiment model. The model produces probabilities for negative, neutral, and positive sentiment. A continuous sentiment score was calculated as the positive probability minus the negative probability, giving a value between -1 and 1.

4. Visualization

The visualization below combines sentiment with tweet volume over time. The x-axis represents the date, while the y-axis represents the average sentiment score. Each circle represents a date with available tweets, and its size represents the number of tweets on that date. Hover over a circle to view the date, sentiment score, and tweet count.

5. Analysis

The cleaned dataset shows how preprocessing can transform heterogeneous web data into a structured dataset suitable for visualization. After cleaning the tweet text and standardizing dates and numerical attributes, sentiment can be compared consistently across time. The visualization shows considerable variation in average sentiment across the observed dates, while the different circle sizes reveal substantial variation in tweet volume. Most average sentiment values are above zero, indicating that positive sentiment was generally more common than negative sentiment in the sampled data. However, higher tweet volume does not consistently correspond to higher sentiment. This suggests that periods of increased online discussion were not necessarily associated with more positive sentiment. Overall, the visualization demonstrates how cleaning, transforming, and enriching web data can reveal patterns that would be difficult to observe directly from the original raw data.

6. Data Pipeline

The workflow used in this project can be summarized as:

  • Collect raw web data
  • Inspect and clean the dataset
  • Normalize and preprocess tweet text
  • Apply RoBERTa sentiment analysis
  • Create tidy, visualization-ready data
  • Aggregate sentiment and tweet volume by date
  • Visualize the cleaned data with D3.js
