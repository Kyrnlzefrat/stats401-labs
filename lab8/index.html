Part B: Semantic Embedding Map

Each passage is represented by a semantic embedding generated using the all-MiniLM-L6-v2 sentence-transformer model. The 384-dimensional embeddings are projected into two dimensions with UMAP. Nearby passages tend to have similar semantic content.

Part C: Passage Details and Semantic Neighbors

Click a passage to inspect its document location, semantic topic, original text, and nearest semantic neighbors. This supports comparison of passages that may occur in different formal sections of the bulletin.

Passage details

Click a point in the semantic map to inspect a passage and its nearest semantic neighbors.

Part D: Semantic Map Interaction

The map uses position to encode the UMAP projection, color to encode semantic topic, and point size to encode passage length. Search, topic filtering, section filtering, and zoom and pan support exploration of the semantic space. Click a point to display its passage details and nearest semantic neighbors.

Part E: Topic × Bulletin Section Matrix

The matrix connects the semantic structure of the corpus with the bulletin's formal organization. Rows represent formal bulletin sections, columns represent semantic topics, and cell intensity represents the number of passages in each section-topic combination.

Part F: Coordinated Interaction

The semantic map and Topic × Section matrix are coordinated. Selecting a semantic passage identifies its corresponding formal section and semantic topic in the matrix. Selecting a matrix cell highlights the passages belonging to that section-topic combination in the semantic map.

How to explore the coordinated views

Click a semantic point to highlight its corresponding matrix cell and inspect nearest semantic neighbors. Click a matrix cell to highlight the matching passages in the semantic map. The search box and filters can be used before or after these selections.
