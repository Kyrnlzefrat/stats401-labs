Part C: Design Description and Temporal Network Questions

C1. Node-Link Design

The temporal node-link view uses color to represent company sector, outline pattern to distinguish geographic region, and node size to represent current-day transaction volume. Link width represents the transaction value associated with a relationship, while link color identifies the transaction type. Links entering the current frame fade in and links leaving the frame fade out, making changes in connectivity visible during animation. Hovering over a node or link provides additional information for the selected time point.

C2. Temporal Interaction Design

The Play, Pause, Reset, and time-slider controls allow users to inspect the full 60-day period either continuously or one day at a time. The current day and date are displayed above the slider, and the summary panel reports active companies, active links, total transaction value, and transaction count. The visualization keeps the same company objects and updates the existing force simulation rather than rebuilding the network from scratch for every day.
